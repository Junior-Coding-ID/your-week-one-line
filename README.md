One line, 95 characters, summing up the week — the win, the fail, the chaos, all of it.

## Entry

> This week I covered eight world news stories and got disqualified by a two-letter copy command.

## How it works

`main.ts` writes the single line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT/entry.txt` when set, for local testing). No arguments, no network, no dependencies.

```sh
node main.ts
```
